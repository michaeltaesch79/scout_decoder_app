AUDIO FILES
===========
Drop your MP3 files in this folder using these names:

ambient.mp3   - looping background ambience/music
verified.mp3  - short sound for a correct mission code
rejected.mp3  - short sound for an incorrect code
finale.mp3    - final victory / birthday music

You can change filenames in config.js.

IMPORTANT: Only use audio you have the rights or permission to use.
Browsers require a user interaction before autoplay; the BEGIN OPERATION button
handles that requirement.
